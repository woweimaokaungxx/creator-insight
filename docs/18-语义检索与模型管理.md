# 18 · 本地语义检索与模型管理（参考 douyin-creator-distill）

## 一、这套功能解决什么

V0.5 计划引入「跨博主找相似预测」的语义检索。本模块把 distill 的
**模型可选 + 自动下载 + 本地向量化** 机制落地到 creator-insight：

- 用户可在「设置页」选 **轻量模式（bge-small-zh-v1.5，96MB）** 或
  **高精度模式（Qwen3-Embedding-0.6B，1.2GB）**；
- 点「下载」即从 **ModelScope 国内源** 自动拉取权重（断点续传，写
  `.download-complete.json` 完成标记）；
- 向量化走本地 **sentence-transformers**，**离线推理**，不依赖云端；
- 对存量 `prediction` 建索引后，可用自然语言查询做语义召回。

> 与 distill 的差别：distill 是 Node 项目，需 spawn 子进程调 Python worker；
> creator-insight 本身就是 Python，因此 **本进程直接加载 SentenceTransformer**，
> 模型句柄按 model_id 缓存复用，无需 subprocess。

## 二、目录与文件

```
app/services/semantic/
  models.py      模型注册表（两档）+ 目录解析 + 安装状态检测
  download.py    自动下载器（modelscope / huggingface，断点续传 + 完成标记）
  embedder.py    本地 sentence-transformers 离线向量化（句柄缓存）
  service.py     编排：设置/选模型/下载/进度/删除/建索引/检索
  __init__.py    暴露单例 semantic_service
app/api_semantic.py   /api/semantic/* 路由
app/db.py             semantic_index 表（向量 BLOB 入库）
config/*.json         semantic_search 段（active_model / model_root / source）
src/pages/Semantic.vue       前端管理页（选模型/下载/进度/删/检索，V0.8 替代旧 static/semantic_models.html）
scripts/doctor.py     [8] 语义检索运行环境检查
```

模型权重落盘位置：`data/models/embedding/<model_id>/`（由
`semantic_search.model_root` 配置，缺省相对 data_dir，落在 H 盘）。

## 三、配置

`config/config.json` 新增段（模板见 `config.example.json`）：

```json
"semantic_search": {
  "enabled": true,
  "active_model": "lightweight",
  "model_root": "./data/models/embedding",
  "source": "modelscope"
}
```

`active_model` 可选 `lightweight` / `high_precision`。

## 四、依赖

下载模型只需两个轻量包；真正向量化还需 sentence-transformers + torch（CPU 版）：

```powershell
# 下载器（必装，才能「自动下载」）
.venv\Scripts\pip install modelscope huggingface-hub

# 向量化（必装，才能建索引/检索；CPU 版 torch 走 pytorch 官方 CPU 源）
.venv\Scripts\pip install sentence-transformers
.venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cpu
```

## 五、API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/semantic/settings` | 列出模型 + 安装状态 + 当前选中 + 运行环境 |
| POST | `/api/semantic/select` | `{active_model}` 切换当前模型 |
| POST | `/api/semantic/download` | `{model_id, source}` 后台下载，立即返回 |
| GET | `/api/semantic/download/{id}` | 下载进度（轮询） |
| DELETE | `/api/semantic/models/{id}` | 删除已下载模型 + 其索引 |
| POST | `/api/semantic/index` | 对存量 prediction 建/重建索引 |
| GET | `/api/semantic/search?q=&limit=` | 语义检索，返回相似预测 |

## 六、使用流程

1. `python scripts/doctor.py` 确认 [8] 下载/向量化依赖就绪；
2. 打开前端「语义检索」页（`http://127.0.0.1:8781/semantic`）→ 选模型 → 点「下载」；
3. 下载完成后点「选用」设为当前模型；
4. 点「重建索引」对已有预测建向量；
5. 输入查询文本做语义召回。

## 七、离线可验收

下载依赖装好后，**全程断网可用**：模型已落盘，sentence-transformers
以 `local_files_only=True` 加载；检索在 SQLite 内做余弦相似度。
仅「下载」这一步需要联网（ModelScope 国内源）。

## 八、与 distill 的对应

| distill | creator-insight |
|---------|-----------------|
| `config/semantic-search.config.json` (`activeModel`) | `config.json` → `semantic_search.active_model` |
| `scripts/manage_embedding_model.py` | `app/services/semantic/download.py`（同逻辑，进程内） |
| `src/services/semantic-model-service.js` | `app/services/semantic/service.py` + `models.py` |
| `semantic_embedding_worker.py` | `app/services/semantic/embedder.py`（进程内加载，无需 worker） |
| `runtime/python/embedding-requirements.txt` | `requirements.txt` 语义段（可选依赖） |
| `.download-complete.json` 标记 | 同机制，下载完成写标记 |
